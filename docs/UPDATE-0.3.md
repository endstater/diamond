# Diamond 0.3

- Иконки Lucide встроены локально вместе с лицензией; типы файлов имеют разные иконки.
- Редактор занимает оставшуюся высоту окна и не сжимается по содержимому.
- Одна глобальная кнопка настроек открывает обычную вкладку: тема, акцент, установленные шрифты, размеры текста и кода, ширина заметки, перенос строк, номера строк, структура, анимация и сброс оформления.
- `Ctrl+F` фокусирует поиск в редакторе; `Ctrl+Shift+F` — поиск по хранилищу. Есть регистр, regexp, подсветка, навигация, замена и выход по Esc. Поиск Markdown работает по его исходнику, сохраняя точные позиции в live-проекции. Синтаксис regexp — Rust regex; ошибки показываются в поле поиска. Подсвечивается до 10 000 совпадений.
- Внизу удалено отдельное сообщение с крестиком, дублировавшее «сохранено»; ошибки показываются рядом с рабочей областью.
- В боковой панели есть «Ваши хранилища» с недавними папками и безопасным переключением через сохранение/подтверждение грязных вкладок.
- Выбор папки и манифеста плагина использует XDG Desktop Portal. При ошибке портала остаётся ручной ввод; обычная отмена диалога не открывает запасное окно.
- Добавление/изменение/удаление файлов отслеживается native inotify через notify. Периодического сканирования нет. Уведомления объединяются после события, отслеживаются только разрешённые директории; `.git`, `target`, `node_modules` и симлинки не обходятся наблюдателем. После установки новых watches выполняется дополнительный снимок, закрывающий гонку регистрации.
- Текстуры SVG, результаты поиска, номера строк и dirty-состояние кэшируются. История документа больше не клонируется на каждом пустом кадре. Фоновые запросы индекса объединяются; запись настроек откладывается после последней правки.

## Своя иконка

Оставьте `diamond2.svg` в корне старой папки проекта рядом с `Cargo.toml`. При запуске приложение ищет его в рабочей папке и в родительских папках бинарника (`target/release` или `target/debug`), затем рядом с установленным приложением. Иконка используется для окна, заголовка и стартовой страницы без пересборки. В архиве самого пользовательского SVG нет; имеющийся файл при распаковке не заменяется.

## Обновление с сохранением кэша

Из старой папки проекта (пути замените на свои):

```sh
tar -xzf ~/Downloads/diamond-0.3.0.tar.gz --strip-components=1
cargo build --release -p diamond-app
./target/release/diamond
```

Первую сборку 0.3 выполните с сетью, без `--offline`: появились зависимости для SVG, regexp, inotify и XDG Portal. Существующие `Cargo.lock` и `target` архив не удаляет. Используйте тот же профиль и toolchain, что в предыдущей сборке; для debug уберите `--release` и запускайте `target/debug/diamond`. `cargo clean` для обновления не нужен.

Порталу нужен установленный `xdg-desktop-portal` и backend с FileChooser для вашего рабочего стола. Список системных шрифтов читается через `fc-list` при первом открытии настроек; без него доступны встроенные варианты.

Сборка и GUI этой редакции ещё не проверены в среде разработки: здесь нет Rust. Выполненные проверки перечислены в `VALIDATION.md`.
