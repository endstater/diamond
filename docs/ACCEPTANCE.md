# Матрица возможностей Diamond

Матрица описывает объём текущего исходного кода. Результаты сборки, автоматических тестов и проверки интерфейса записываются отдельно в [VALIDATION.md](VALIDATION.md). Полная совместимость с Obsidian и VS Code в эту версию не входит.

| Область | В текущей реализации | Граница поддержки |
| --- | --- | --- |
| Desktop | Rust + egui/eframe, нативное окно, OpenGL, чёрно-серая тема, векторные иконки, увеличенные скругления и нижняя панель, единые отступы | Проверка реального окна, IME, сеток и буфера обмена нужна на целевом рабочем столе |
| Хранилище | Обычная папка, дерево файлов, вкладки, выбор хранилища | Файловая синхронизация и Publish исключены из продукта |
| Форматированный Markdown | Только `.md`/`.MD`; одно поле с раскрытием реального Markdown в активном блоке, редактирование `#`/`**`/`*` без кнопок форматирования, семантическое оформление остальных блоков | Раскрытие идёт по активному блоку целиком. Ссылки, wikilinks, таблицы, HTML и вложенные конструкции вне схемы остаются видимым исходником |
| Автосохранение | Форматированные `.md` сохраняются после 600 мс покоя и перед закрытием; конфликт оставляет буфер грязным и останавливает повторы; IME-кандидаты не записываются | Source/Hex требуют ручного сохранения; синхронная атомарная запись рассчитана на небольшие заметки |
| Сохранность Markdown | Исходные байты нетронутых блоков, сохранение неизвестных конструкций | Изменённый поддерживаемый блок может получить канонический Markdown |
| Unicode | Публичные операции документа используют позиции Unicode scalar values; байтовые позиции преобразуются явно | Графемное перемещение курсора относится к нативному GUI |
| Undo/redo | Семантические правки текста, форматирования и блоков; ввод исходника через egui | Переход из изменённого исходника в форматированный режим начинает новую семантическую историю |
| Исходный код | UTF-8 текст, номера строк, нативное выделение, элементарная подсветка, буквальный поиск и замена | LSP, completion, diagnostics, folding, multicaret и отладчик запланированы отдельно |
| Двоичные файлы | Явный hex-режим, проверка корректности перед сохранением | Файлы ограничены 32 MiB; виртуализированного редактора больших файлов пока нет |
| Безопасные пути | Проверка относительных путей, отказ для `..`, абсолютных путей и симлинков | Это файловая политика приложения, а не изоляция от процессов с правами пользователя |
| Сохранение | Сравнение с загруженными байтами, временный файл в той же папке, fsync и атомарная замена, создание без перезаписи | Между последней проверкой и rename остаётся окно гонки; журнал версий и межпроцессная блокировка ещё нужны |
| Несохранённые изменения | Автоматический flush форматированных заметок; Save/Discard/Cancel для Source/Hex и неудачных сохранений | Сбой процесса до сохранения не покрыт журналом восстановления |
| Индекс | Заголовки, wikilinks, теги, задачи, backlinks и простой поиск | Ограниченный Markdown-сканер; индекс пересоздаваемый, до 50 000 записей, Markdown до 2 MiB |
| Настройки | Обычная вкладка, Dark/Light/System, акцент, встроенные/системные шрифты, размеры текста/кода, ширина, перенос, номера строк, инспектор, reduced motion | Системные шрифты требуют fc-list; CSS API отсутствует |
| Плагины | Собственные манифесты и протокол v1, любой язык, отдельные процессы, явный запуск, таймауты и лимиты | Доступ через протокол ограничен возможностями; процесс имеет обычные права пользователя ОС. Совместимость с чужими API не реализована |
| Excalidraw | Архитектура отдельного необязательного помощника определена | Сам помощник ещё не реализован; WebKitGTK отсутствует в основной сборке |
| Пакет Arch | Локальный PKGBUILD, desktop entry, SVG-иконка | Публикация AUR и проверенная сборка для каждой архитектуры — отдельные этапы |
| Зависимости | egui/eframe зафиксированы прямыми версиями, проверка запрещённых браузерных runtime-пакетов в `scripts/check.sh` | При отсутствии Cargo.lock первоначальное разрешение остальных зависимостей требует сети |

Для принятия desktop-сборки на Arch выполните `scripts/check.sh`, соберите release и проверьте окно в Wayland и X11: Unicode/IME, непрерывное выделение, режимы редактора, undo форматирования, конфликт внешнего сохранения, повреждённый hex, dirty-диалоги и явный запуск тестового плагина. Отмечайте выполненные проверки с окружением в `VALIDATION.md`.

В 0.3 добавлены Lucide с лицензией, поиск по исходнику с регистром/regexp/подсветкой/фокусом, список недавних хранилищ, XDG-выбор папок/манифестов с ручным fallback и inotify-события без периодического сканирования. Свой diamond2.svg подхватывается при запуске. Эти UI/portal/filesystem сценарии требуют проверки на целевой машине; см. VALIDATION.md.

## Изменения 0.4

Inline-ссылки и wikilinks имеют семантическую подпись и адрес, Ctrl+щелчок открывает HTTP(S) в системном браузере или найденную заметку. Якоря пока не прокручивают заметку до заголовка. Круглые задачи кликабельны, `---` рисуется разделителем. Простые плоские списки поддерживаются; сложные вложенные/многоабзацные списки сохраняются как исходник обычным шрифтом.

Папки свёрнуты по умолчанию, поиск файла показывает совпадения с предками. ПКМ позволяет удалить файл/папку с подтверждением; удаления и потеря несохранённых правок не отменяются через undo. Карточки поиска имеют общую ширину и кликабельны целиком. Вкладки занимают ширину рабочей области. Языки: English (по умолчанию), Русский, 简体中文; шрифт и размер интерфейса независимы от редактора. Для иероглифов нужен системный CJK-шрифт.

## Изменения 0.5

Ползунки применяются при отпускании. Переименование файла в ПКМ сохраняет грязный буфер и отказывает при занятом имени. Удалена дополнительная строка пути под вкладками. Простые списки/ссылки остаются оформленными при пустых и частично введённых пунктах; в активном пункте не рисуется дублирующий маркер. Курсор на пустой строке после блока скрывает разметку предыдущего блока.

Таблицы GFM имеют сетку, выравнивание и inline-оформление; редактирование раскрывает Markdown. Широкая таблица может расширить горизонтальную область редактора. Изображения отдельным блоком поддерживают PNG/JPEG/GIF (один кадр)/WebP, alt/title; локальные — из хранилища, HTTP(S) — по нажатию. Встроенные картинки среди обычного абзаца, SVG и анимация GIF пока остаются за границей. При сетевой ошибке виден placeholder с ошибкой по наведению.

Блоки кода имеют фон и общую с Source грамматическую подсветку Syntect. По расширению/языку доступны стандартные встроенные грамматики; TypeScript использует JS fallback, неизвестные языки — обычный текст. Найденный цикл repaint при unfocused-окне исправлен в исходнике; CPU на целевой машине ещё не измерен.
