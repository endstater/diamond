# Пакет Arch Linux

`PKGBUILD` для Arch Linux x86_64 собирает локальный архив исходников `diamond-0.5.0.tar.gz` с корневой папкой `diamond-0.5.0/`. Это заготовка локального пакета, а не опубликованный пакет AUR.

Положите архив рядом с `PKGBUILD`, затем выполните:

```sh
makepkg -si
```

Если в снимке исходников нет `Cargo.lock`, подготовка сначала создаёт его. Первичное разрешение версий требует сети; такой снимок ещё не фиксирует всё дерево зависимостей. Сохраните полученный lockfile вместе с исходниками для последующих сборок.

Подготовка загружает зависимости из lockfile, сборка использует `--frozen`, а `check()` запускает проверки из `scripts/check.sh`. Для последующих сборок без сети сначала заполните кеш Cargo. Проверки и сборка требуют установленного `rustfmt` и `clippy`.

При передаче пакета другим пользователям замените `SKIP` в `sha256sums` настоящей контрольной суммой с помощью `updpkgsums`. Поддержка архитектур в PKGBUILD обозначает цель сборки; выполненные проверки перечислены отдельно в `docs/VALIDATION.md`.

Устанавливаются исполняемый файл `diamond`, пункт меню приложений, SVG-иконка, лицензия и README. WebKitGTK не требуется для основного приложения.
