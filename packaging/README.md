# Установка на Arch Linux

## Из вашей текущей папки проекта

После обновления исходников:

```sh
cd ~/diamond-0.1.0/packaging
makepkg -si -p PKGBUILD.local
```

`PKGBUILD.local` собирает checkout на каталог выше, используя его существующий
`target`; он не запускает cargo clean и не копирует проект во временный каталог.
Работает на x86_64 и aarch64 как рецепт сборки; эти архитектуры здесь не проверены.
На машине нужны `base-devel`, `rust`, `cargo`, `pkgconf` и `librsvg` (утилита `rsvg-convert`). Сборку запускайте обычным
пользователем; makepkg запросит sudo для зависимостей и установки через pacman.
Cargo может обновить Cargo.lock и загрузить новые зависимости.

Устанавливаются `/usr/bin/diamond`, ярлык
`/usr/share/applications/io.diamond.Diamond.desktop`, SVG и PNG-иконки, лицензии
и README. Идентификатор ярлыка и иконки совпадает с app ID окна в Wayland.
Иконка берётся из `diamond.svg` в корне проекта, а если его нет — из
`assets/diamond.svg`. PNG создаются при упаковке в размерах 16, 24, 32, 48, 64,
128, 256 и 512 пикселей. Устанавливаются имена `io.diamond.Diamond` и `diamond`
в hicolor, плюс PNG в `/usr/share/pixmaps` для совместимости. Зависимость
`hicolor-icon-theme` обеспечивает базовую тему поиска иконок на минимальной
системе. Конвертер нужен только при сборке; приложение не конвертирует иконки
в фоне. После обновления пакета заново откройте лаунчер. Основному приложению не нужен WebKitGTK. Git нужен для GitHub-установки
плагинов, Python — только для Python-плагинов, xdg-desktop-portal — для выбора
файлов/папок. Для цветных эмодзи можно установить `noto-fonts-emoji`, для китайского
текста — `noto-fonts-cjk`. Montserrat должен быть установлен в системе; список
шрифтов больше не ограничен 256 записями. После установки шрифта перезапустите app.

`PKGBUILD.local` не заменяет проверки разработчика: `cargo fmt --all`, затем
`./scripts/check.sh`. Сама Rust-сборка этого снимка в подготовительной среде
не выполнялась.

## Из отдельного архива исходников

Обычный `PKGBUILD` предназначен для полного архива `diamond-0.7.5.tar.gz` с корнем
`diamond-0.7.5/`, лежащего рядом с ним. Это иной архив, не обновление `-files`.
Для него `makepkg -si` сначала подготавливает зависимости и запускает check().
Перед распространением замените SKIP настоящей SHA256 через updpkgsums.
Эти рецепты не означают публикацию в AUR или официальный репозиторий Arch.
